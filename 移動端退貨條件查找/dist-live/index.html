更新 Excel 後，讓系統資料同步

電腦版使用者

  1. 把新版 Excel 放在這個資料夾：本專案資料夾
  2. 在 Excel 選「另存新檔」，檔名存成 source.xlsx。
  3. 不用關掉其他 Excel 檔，但請確認 source.xlsx 已儲存完成。
  4. 雙擊資料夾裡的 更新廠商資料.bat。
  5. 看到更新完成後，重新開啟或重新整理這個網頁。

手機版使用者

  1. 先在這台電腦完成上面的 Excel 更新步驟。
  2. 重新產生手機版檔案，或請負責維護的人產生新版。
  3. 把新版 return-rule-finder-mobile.zip 傳到手機。
  4. 手機解壓縮後，打開裡面的 return-rule-finder.html。

手機不能開 127.0.0.1 的網址，因為那只代表目前這台裝置。手機請用離線 HTML 檔，或請資訊人員放到公司內網網址。

手機版是離線檔案，單純修改 Excel 不會自動更新到手機；每次 Excel 改版後，都要重新傳新版手機檔。
