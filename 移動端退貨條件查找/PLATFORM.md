# 不同裝置怎麼使用？｜新手指南

這份文件說明同一個退貨查詢工具，如何在電腦、手機或網站上使用。

**你不需要把所有方式都設定一遍。** 如果只是自己使用，電腦直接開檔案、Android 手機使用離線包就可以了。查詢操作及 Excel 更新方式請看 [README.md](./README.md)。

## 1. 先選擇適合你的方式

| 你想做什麼 | 建議方式 | 需要電腦一直開著嗎？ |
|---|---|---|
| 自己在電腦查詢 | 直接開啟 `index.html` | 使用時開著即可 |
| Android 手機隨時離線查詢 | 手機離線 HTML 包 | 不需要 |
| 手機暫時連到電腦測試 | 區域網路預覽 | 需要，預覽服務也要保持啟動 |
| 多人共用同一份網站資料 | 公司內網或網站 | 提供網站的主機需要保持服務 |
| 用手機主畫面圖示開啟網站 | PWA，也就是可加入主畫面的網站 | 視網站主機及離線快取狀態而定 |
| 在網路上展示功能 | 獨立示範網站 `dist-demo` | 部署後不必開著自己的電腦 |
| 想做成可安裝的 APK 或 iOS App | 原生 App 包裝，需要開發工具 | 打包後使用不依賴原開發電腦 |

「本機」就是你正在操作的裝置；「部署」就是把網站檔案放到能透過網址提供服務的主機上。

## 2. 電腦直接使用：最少步驟

適合只想在一台或幾台電腦查詢的人。

1. 下載或複製整個專案資料夾。
2. 如果是 ZIP，先解壓縮。
3. 用 Edge 或 Chrome 開啟 `index.html`。
4. 開始查詢。

不用安裝 Node.js、Python 或 Codex，也不需要架網站。檔案網址顯示為 `file:///...` 是正常的。

**不要只複製根目錄的 `index.html`。** 它還需要旁邊的 `app.js`、`styles.css` 和 `vendors-data.js`。如果想只傳一個 HTML，請使用下一節介紹的單檔離線版。

## 3. Android 手機離線使用：不必連到電腦

適合網路不穩、手機與電腦網路無法互通，或不想把資料放到網站上的情況。

1. 取得最新版 `return-rule-finder-mobile.zip`。
2. 傳到手機並下載到手機儲存空間。
3. 使用手機的檔案管理工具解壓縮。
4. 選擇用 Chrome 等瀏覽器開啟 `return-rule-finder.html`。

這份 HTML 已內含畫面、程式和廠商資料。平常查詢不需要網路，電腦也可以關機。

### 怎麼取得新版手機包？

維護者修改 `source.xlsx` 後，執行「更新廠商資料.bat」。成功完成會產生新版手機 ZIP，再傳到手機重新解壓縮即可。

如果只是程式或畫面有變動，而資料已經準備好，維護者也可以在專案資料夾執行：

```powershell
npm run build:single
```

這個指令需要 Node.js，會更新：

- `dist/return-rule-finder.html`
- `dist/iphone-open-this.html`
- `dist/vendors.json`
- `dist/使用說明.txt`
- 根目錄的 `return-rule-finder-mobile.zip`

**手機端使用者不用執行這些指令，只要接收新版 ZIP。** 檔名雖然包含 `iphone-open-this.html`，也不代表 iPhone 一定能直接執行本機檔案；iOS 的檔案預覽與瀏覽器限制需另外確認。

## 4. 手機連到電腦上的預覽網站

適合開發或臨時測試。這個方式依賴電腦與手機之間的網路連線。

### 電腦端

先安裝 Node.js，在有 `package.json` 的專案資料夾開啟終端機，執行：

```powershell
npm run preview
```

保留這個視窗。電腦自己可以開啟：

```text
http://127.0.0.1:4173/
```

結束預覽時，在終端機按 `Ctrl+C`。

### 手機端

1. 手機連上可與電腦互通的 Wi-Fi。
2. 電腦開啟命令提示字元，輸入 `ipconfig`。
3. 找目前使用的網路介面下的 IPv4 位址。電腦插網路線時，通常看「乙太網路卡」。
4. 在手機瀏覽器輸入 `http://電腦的IPv4位址:4173/`。

例如電腦 IP 是 `192.168.1.100`，手機就輸入 `http://192.168.1.100:4173/`。這只是範例，請換成實際位址。

### 連不上的時候

- 電腦插網路線、手機用 Wi-Fi 也可以連線，前提是網路設備允許互通。
- 都能上網，不代表手機一定能連到電腦。訪客 Wi-Fi、公司網路隔離和防火牆都可能阻擋。
- 手機與電腦 IP 不同網段時，是否能連線取決於網路的路由與存取設定，不能只看 IP 就斷定。
- `127.0.0.1` 只代表目前操作的裝置。手機輸入它，不會連到電腦。
- 電腦關機、休眠或預覽服務停止後，手機就無法再連到這個預覽網站。

若無法調整網路，直接使用 Android 離線包即可，不必為了查詢而設定網路。

## 5. 多人共用：把工具放到公司內網或網站

適合多人要查詢同一份資料，並希望由維護者集中更新的情況。

### 維護者先產生網站檔案

在專案資料夾執行：

```powershell
npm run build:live
```

會產生 `dist-live` 資料夾和 `return-rule-finder-live.zip`。

接著把 **`dist-live` 裡面的檔案**交給網站或資訊管理人員，放到能提供靜態網頁的主機上。使用者只需取得網站網址，用瀏覽器開啟。

這個打包指令只產生檔案，不會自動建立網站、不會自動上傳 GitHub，也不會自動啟用網站服務。

### 資料更新方式

1. 維護者更新 Excel 並執行資料更新工具。
2. 同步網站上的 `vendors.json` 和 `vendors-data.js`；也可以重新產生、部署整份 `dist-live`。
3. 使用者重新開啟或重新整理網站。

網站會優先讀取 `vendors.json`；讀取失敗時使用 `vendors-data.js`。兩份資料一起更新，可避免使用備用資料時出現舊內容。

## 6. PWA 是什麼？和手機離線包有什麼不同？

PWA 可以理解成「能從主畫面圖示開啟的網站」，通常仍由瀏覽器提供功能，不是 APK 安裝檔。

本專案的正式網站版包含主畫面設定及離線快取程式。網站經由 HTTPS 提供服務，且瀏覽器支援時，可以使用瀏覽器提供的安裝或加入主畫面功能。

| 項目 | PWA 網站版 | HTML 手機離線包 |
|---|---|---|
| 第一次開啟 | 需要能連到網站 | 接收檔案、解壓縮後開啟 |
| 平常怎麼開 | 網址或主畫面圖示 | 手機上的 HTML 檔 |
| 離線使用 | 需先成功載入並完成快取，實際取決於瀏覽器 | 程式與資料已包在檔案中 |
| 更新方式 | 維護者更新網站，使用者重新載入 | 重新接收新版離線包 |

一般的區域網路 `http://電腦IP:4173/` 可以拿來預覽，但不一定具備 PWA 安裝與離線快取所需的條件。不要把「網站開得了」直接當成「一定能離線使用」。

**獨立示範版 `dist-demo` 沒有啟用 Service Worker 離線快取**，用途是線上功能展示，與正式版的 PWA 功能不同。

## 7. 只放虛構資料的網路展示

若目的是把功能展示給別人看，請使用獨立測試版：

```powershell
npm run build:demo
```

輸出在 `dist-demo`，有 5 筆虛構廠商資料，可測試黃綠紅結果、禁退、人工確認及不同品項。

1. 另外建立示範用的網站或儲存庫。
2. 只上傳 `dist-demo` 裡的檔案。
3. 若使用 GitHub，還需設定網站發布服務；單純上傳程式檔案不會自動變成網站。
4. 不要把正式 Excel、正式資料 JSON、正式離線 HTML 或手機 ZIP 混進示範網站。

`build:demo` 只更新資料夾，不會自動更新 `return-rule-finder-demo.zip`；如要傳送新版 ZIP，請自行重新壓縮該資料夾的內容。

正式資料與示範資料請分開保存。離線 HTML 和 ZIP 也可能內嵌完整廠商資料，不能只檢查 Excel 或 JSON。

## 8. APK 和 iOS App：進階需求再處理

### Android APK

APK 是 Android 的應用程式安裝檔。本專案有 Capacitor 相關設定，可以作為包裝成 App 的起點。

開發人員需要準備 Node.js、Android Studio 及相容的 Android 建置環境，再安裝專案套件、加入 Android 平台、同步網頁檔案、建置並簽署 APK，最後在實機測試。

**目前的手機 ZIP 是離線網頁包，不是 APK。** 執行網頁打包指令也不會自動產生 APK。

### iPhone／iPad App

原生 iOS App 需要 macOS、Xcode，以及相應的簽署與發佈設定。這與把 HTML 傳到手機是不同流程，建議交由熟悉 iOS 的開發人員處理。

### 維護者注意

目前 `capacitor.config.json` 的 `webDir` 指向專案根目錄。在正式包裝前，應先調整為整理好的專用網頁成品目錄，核對包入的資料及檔案，再進行建置。這份文件沒有表示 APK 或 iOS App 已經完成打包及實機驗證。

對目前只是要查詢的使用者，優先使用電腦版、Android 離線版，或已部署的網站即可。

## 9. 哪些檔案負責什麼？

| 檔案或資料夾 | 用途 |
|---|---|
| `index.html` | 網頁畫面與欄位 |
| `app.js` | 查詢、月份計算和結果顯示 |
| `styles.css` | 排版與顏色 |
| `source.xlsx` | 原始廠商 Excel |
| `vendors.json`、`vendors-data.js` | 程式使用的廠商資料 |
| `manifest.webmanifest`、`service-worker.js`、`icon.svg` | 正式網站版的安裝資訊、快取與圖示 |
| `dist` | 手機單檔離線版成品 |
| `dist-live` | 以目前資料產生的網站部署成品 |
| `dist-demo` | 只有虛構資料的獨立展示成品 |
| `tools` | 資料更新和打包工具 |
| `capacitor.config.json` | 進階原生 App 包裝設定 |

如果只要查詢，不需要修改程式。若要修改廠商資料、更新 GitHub 或排除問題，請接著看 [README.md](./README.md)。
